# Olinfo
 My submissions from training.olinfo.it (currently missing terry problems)

 Everything is written in **C++**.

 The source folder contains a "bits" folder, that helps compiling faster by using a pre-compiled series of common headers made by the command "g++ -c bits/stdc++.h". Therefore, the most recent files use "bits/stdc++.h" instead of <bits/stdc++.h>. I did not use <bits/stdc++.h> as the pre-compiled header because the file size was over 100MiB and GitHub did not like it.

 The source folder also contains example input and output .txt files and an "a" executable file, used to test the code, as well as a grader file.
