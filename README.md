# Olinfo
 My submissions from training.olinfo.it (currently missing terry problems)

 Everything is written in **C++**.

 The source folder contains a "bits" folder, that helps compiling faster by using a pre-compiled <bits/stdc++.h> header made by the command "g++ -c bits/stdc++.h". Therefore, the most recent files use "bits/stdc++.h" instead of <bits/stdc++.h>. The binary file is not included in the repo.

 The source folder also contains example input and output .txt files and an "a" executable file, used to test the code, as well as a grader file.

 **DO NOT ABUSE!** You should always try the problem before reading the solution and understand the concept behind it before submitting it.
